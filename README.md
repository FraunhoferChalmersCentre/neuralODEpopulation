## Overview

This repository builds on the framework introduced in [Laurie & Lu (2023)](https://www.nature.com/articles/s41540-023-00317-1), which uses Neural-ODEs for tumor dynamic modeling and overall survival prediction. While the original method shows strong predictive performance, it lacks tools for estimating population-level parameters.

This project aims to improve upon those limitations by refining the inference procedure and extending the model to support population-level parameter estimation.
