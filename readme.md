This repository provides a complete workflow for generating PK/PD or tumor-growth datasets and training Neural-ODE–based deep learning models on them. It includes utilities for simulating realistic pharmacometric data, preparing datasets, building models, and evaluating model performance through diagnostics such as VPCs, latent-space visualizations, and individual fits. The goal of the repository is to offer a flexible, end-to-end pipeline for experimenting with Neural ODE and VAE architectures in both simulated and clinical settings.

The generate_data script is responsible for producing synthetic datasets that mimic pharmacokinetic, pharmacodynamic, or tumor-growth behavior. It allows the user to configure parameters such as dosing schedules, inter-individual variability, PK parameters, tumor-growth dynamics, and residual noise. The generated datasets are exported as CSV files and serve as input for downstream model training. This script is designed to create reproducible, well-structured datasets suitable for testing Neural-ODE training pipelines.

The main_simulated_data script runs the complete training pipeline on the simulated datasets. It loads the generated CSV files, computes normalization statistics, and prepares dataloaders. It then constructs the Neural ODE architecture—including the Transformer encoder, ODE dynamics function, decoder, and learned noise model—and trains two models: a deterministic “median” model and a probabilistic EBVAE model. After training, it produces a variety of diagnostic plots such as VPCs, encoder histograms, and individual fits, enabling a thorough assessment of model performance.

The main_clinical_data script mirrors the simulated pipeline but is tailored to real clinical datasets. It includes additional preprocessing steps for handling irregular sampling, missing values, covariates, and real-world dosing patterns. The same Neural-ODE/EBVAE framework is applied to clinical cases, allowing the user to fit latent-variable ODE models to patient data and produce diagnostics consistent with pharmacometric modeling standards.
